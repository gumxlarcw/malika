Q: Do I need to update existing datasources?
A: No. They continue to work as before.

Q: What if the BPS API changes?
A: Update URL template in datasource config, no code changes needed.

Q: How long does a full fetch take?
A: 15-25 seconds (depends on BPS API response time).

Q: Can I cache multiple keywords?
A: Yes. Each keyword is cached separately.

Q: What happens if fetch fails?
A: Error response with details, no partial data saved.

Q: Can I use this without BPS_API_KEY?
A: No. API key is required (config it in .env).

Q: Will this work with Metabase?
A: Yes. Same ProcessedCache table, same format.
