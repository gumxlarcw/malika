# MALIKA - Panduan Pengguna & Tutorial PWA

## 📱 Cara Install MALIKA sebagai Aplikasi (PWA)

MALIKA adalah Progressive Web App (PWA) yang dapat diinstall di berbagai perangkat. Setelah diinstall, aplikasi dapat diakses langsung dari home screen tanpa perlu membuka browser.

### 🍎 iPhone/iPad (iOS)

> ⚠️ **Penting:** Fitur install PWA di iOS hanya tersedia di Safari. Jika menggunakan Chrome atau browser lain, buka link MALIKA di Safari terlebih dahulu.

1. **Buka MALIKA di Safari**
   - Akses `https://malika.bpsmalut.com` menggunakan Safari

2. **Ketuk tombol Share**
   - Cari ikon Share (kotak dengan panah ke atas) di bagian bawah layar Safari
   - ![Share Button](https://help.apple.com/assets/65DD3ECE85A8BDFB51028A08/65DD3ED085A8BDFB51028A11/id_ID/cd4c22e7cace44dd7ba5dd78b96c7063.png)

3. **Pilih "Add to Home Screen"**
   - Scroll ke bawah pada menu yang muncul
   - Ketuk opsi "Add to Home Screen"

4. **Konfirmasi instalasi**
   - Ketuk "Add" di pojok kanan atas
   - Aplikasi MALIKA akan muncul di home screen Anda

### 🤖 Android

#### Chrome (Direkomendasikan)

1. **Buka MALIKA di Chrome**
   - Akses `https://malika.bpsmalut.com`

2. **Metode 1: Banner Install (Tercepat)**
   - Jika muncul banner "Install MALIKA" di bagian bawah layar, ketuk langsung tombol "Install"

3. **Metode 2: Menu Browser**
   - Ketuk ikon menu ⋮ (tiga titik vertikal) di pojok kanan atas
   - Pilih "Install app" atau "Add to Home screen"
   - Ketuk "Install" pada dialog konfirmasi

#### Samsung Internet Browser

1. Ketuk menu ≡ (tiga garis horizontal) di pojok kanan bawah
2. Pilih "Add page to" → "Home screen"
3. Atau pilih "Install" jika opsi tersedia

#### Browser Lain

Untuk pengalaman terbaik, disarankan menggunakan Chrome. Browser lain mungkin tidak mendukung semua fitur PWA.

### 💻 Desktop (Windows/Mac/Linux)

#### Chrome / Microsoft Edge

1. **Buka MALIKA di browser**
   - Akses `https://malika.bpsmalut.com`

2. **Metode 1: Ikon di Address Bar**
   - Cari ikon install (⊕ atau 📥) di sebelah kanan URL
   - Klik ikon tersebut dan pilih "Install"

3. **Metode 2: Menu Browser**
   - Klik menu ⋮ di pojok kanan atas
   - Pilih "Install MALIKA..."
   - Klik "Install" pada dialog konfirmasi

#### Firefox

Firefox belum sepenuhnya mendukung instalasi PWA. Alternatif:
- Gunakan Chrome atau Edge untuk install
- Atau bookmark halaman untuk akses cepat

## 🎯 Fitur Guided Tour (Tutorial Interaktif)

MALIKA memiliki fitur guided tour yang akan memandu Anda menggunakan aplikasi. Tour ini akan muncul secara otomatis saat pertama kali mengakses aplikasi.

### Kapan Tour Muncul?

- **Otomatis**: Saat pertama kali membuka aplikasi
- **Manual**: Melalui menu Settings → "Mulai Tutorial"

### Apa yang Dipelajari?

Tour interaktif akan menjelaskan:

1. **Dashboard** - Ringkasan data statistik Maluku Utara
2. **Chat MALIKA** - Cara bertanya tentang data statistik
3. **Berita Resmi Statistik** - Akses publikasi BRS terbaru
4. **Publikasi** - Jelajahi publikasi statistik lengkap
5. **Notifikasi** - Pengaturan notifikasi
6. **Pencarian Cepat** - Cara mencari data
7. **Mode Gelap/Terang** - Mengubah tampilan aplikasi
8. **Instalasi PWA** - Panduan install sesuai perangkat

### Mengulang Tour

Jika ingin melihat tour lagi:

1. Buka menu **Settings** dari sidebar
2. Scroll ke bawah ke bagian "Tutorial aplikasi"
3. Klik tombol **"Mulai Tutorial"**

## 🔔 Push Notification

Untuk menerima notifikasi update data terbaru:

1. Buka menu **Settings**
2. Klik **"Minta izin"** untuk memberikan izin notifikasi
3. Aktifkan **Push Notification** dengan klik "Aktifkan push"

> 💡 **Tips:** Install MALIKA sebagai PWA terlebih dahulu untuk pengalaman notifikasi terbaik.

## ❓ FAQ

### Mengapa saya tidak bisa install di iPhone?
- Pastikan Anda menggunakan Safari. Browser lain di iOS tidak mendukung instalasi PWA.

### Banner install tidak muncul di Android?
- Coba akses melalui menu browser (⋮ → Install app)
- Pastikan menggunakan Chrome versi terbaru
- Clear cache browser dan coba lagi

### Aplikasi tidak update?
- Di PWA, buka aplikasi dan tunggu beberapa detik untuk auto-update
- Atau uninstall dan install ulang aplikasi

### Push notification tidak bekerja?
- Pastikan izin notifikasi sudah diberikan di Settings browser/OS
- Aktifkan push di menu Settings MALIKA
- Beberapa browser memblokir notifikasi - periksa pengaturan browser
